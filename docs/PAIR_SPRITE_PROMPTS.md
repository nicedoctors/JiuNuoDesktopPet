# 双宠互动图像生成输入

以下六套动作表的唯一参考图分别是 `assets/characters/feibijiubi/original.png` 和 `assets/characters/nuonuo/original.png`。使用内置 imagegen 直接从对应原图生成独立的 4×4 动作表，再以 `tools/process_pair_sprites.py` 确定性拆帧。`assets/pair_interactions/previews/pair-sprite-manifest.json` 记录选定源图及每帧哈希。禁止把生成动作表或运行时帧再次作为模型输入。

所有提示共有约束：16 格按行优先组成连续时间线；每格人物正面或轻微朝互动对象侧转，保持相同镜头尺寸和脚底基线，完整保留头顶与两只脚；独立人物、透明或纯白背景、无另一个角色、无场景和文字。菲比啾比必须保留白色黑蓝边大帽、金发、蓝十字发卡、紫色有高光眼、白黑蓝制服、黑手套及条纹袜；糯糯必须保留灰蓝长发、无瞳孔的粉蓝双色眼、红白衣服、红蝴蝶结和双脚。
